# Privacy Policy

**Effective date:** August 11, 2026

AVIM Vietnamese IME does not collect, sell, or transmit user data.

The extension processes keystrokes locally in webpage text fields and
contenteditable areas to provide Vietnamese input. Keystrokes and webpage
content are not sent to any server.

The extension stores only user preferences locally using Chrome's
`chrome.storage.local`, including the selected input method and enable/disable
settings. It does not store page content or keystrokes.

The extension does not use analytics, advertising, tracking, or remote code.
It does not make external network requests.

Privacy questions can be submitted through the project's issue tracker:
<https://github.com/viethoangcr/avim-chrome/issues>
